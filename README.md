# 当骰一棒

《当骰一棒——AI 决策 · 多人回合制桌游》是面向大学生朋友聚会和轻量线上联机的浏览器游戏。玩家加入房间后轮流投掷移动骰和工具骰，在立体方格地图中选择路线、使用道具并争夺终点；人数不足时由智能体对手根据局面自主决策补位。

本仓库已完成可运行的本地原型，用于验证从创建房间到人机回合推进的核心流程。

## 拟用技术

- TypeScript、Vue 3、Vite
- Three.js
- Node.js、Colyseus
- SQLite
- 云端模型 API 与规则策略降级

## 当前范围

MVP 只完成“一名玩家创建房间，加入两名智能体，完成一局竞速并得到结算结果”的核心流程。关卡编辑器、账号系统、语音、商业化和复杂小游戏不在本学期范围内。

当前原型已经实现：

- 创建本地练习房间，配置1—3名策略智能体
- Three.js立体方格棋盘、墙体与特殊地块
- 移动骰、工具骰、可达落点计算和服务端规则前的本地验证逻辑
- 工具、泥潭和加速地块
- 智能体寻路、风险判断、工具偏好及行动理由
- 回合推进和终点结算
- 桌面与窄屏响应式布局

## 本地运行

```powershell
npm install
npm run dev
```

生产构建：

```powershell
npm run build
```
