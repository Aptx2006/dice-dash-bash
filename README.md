# 当骰一棒

《当骰一棒——AI 决策 · 多人回合制桌游》是面向大学生朋友聚会和轻量线上联机的浏览器游戏。玩家加入房间后轮流投掷移动骰和工具骰，在立体方格地图中选择路线、使用道具并争夺终点；人数不足时由智能体对手根据局面自主决策补位。

本仓库已完成可运行的本地原型，用于验证从创建房间到人机回合推进的核心流程。

## 当前范围

MVP 完成“一名玩家创建房间，配置规则智能体，完成一局竞速并得到结算结果”的核心流程。关卡编辑器、账号系统、语音、商业化和复杂小游戏不在本学期范围内。

当前原型已经实现：

- 创建本地练习房间，配置1—7名策略智能体
- Three.js立体方格棋盘、墙体与特殊地块
- 移动骰、工具骰、可达落点计算和服务端规则前的本地验证逻辑
- 工具、泥潭和加速地块
- 策略智能体寻路、风险判断、工具选择及出牌演出
- 回合推进和终点结算
- 本地自动存档：首页继续对局或查看上局结果，刷新后保留骰值、手牌、奖励与回合进度
- 基础教学、慢速动画与可调倍速、固定2.5D视角和棋盘自适应
- 桌面与窄屏响应式布局
- 对局内战术助手：模型自主查询局面、合法行动、隔离推演与规则来源，玩家确认后执行一步移动类行动

自动存档仅保存最近一局，使用当前浏览器的本地存储。点击“返回首页”可稍后继续，覆盖未完成存档前会询问。浏览器禁止保存时会显示警告，退出前再次提示。离线期间计时暂停；尚未提交的方向选择、中断的动画和未确认的助手建议不会恢复。当前机器人使用规则策略；首页规则教练已接入云端LLM与关键词RAG，对局内战术助手已具备单Agent工具循环与运行时Harness。云端智能对手与真实联网仍属于后续开发范围。

## 规则教练

模型密钥仅在服务端配置，默认模型为`qwen3.8-flash`。设置本地环境变量`DASHSCOPE_API_KEY`，或按`.env.example`填写本地`.env`，分别启动`npm run coach`和`npm run dev`，即可在首页提问并展开规则出处。

知识库由当前源码确认的20条规则组成，不包含设计计划。运行记录、固定题集与复现方法见[实验5说明](docs/experiment5/README.md)。

## 战术助手

启动相同的AI服务后，在对局中打开“战术助手”，投骰动画结束后选择目标并分析。模型可调用4个只读工具，比较移动、冲刺、瞬步和瞬移；界面展示行动效果、风险、规则来源及分析记录。按“确认执行”才会消耗手牌。放弃、超时、取消、退出或局面变化均不会自动出牌，建议最多保留60秒。助手分析期间可以继续手动操作，计时对局的时钟也继续运行。

运行时最多8步，每次模型调用12秒、工具2秒、整次45秒，最多2次纠错。服务不可用时可继续正常游玩。该功能是一步战术建议，不保证最优路线，也不接管规则机器人。当前对局仍由本地客户端管理，尚不具备联机权威服务端。实现边界和工具接口见[战术助手与运行时Harness](docs/战术助手与运行时Harness.md)。

固定合成局面的真实模型示例（不会更改浏览器存档）：

```powershell
npm run agent:demo -- --scenario=movement
npm run agent:demo -- --scenario=finish
```

加`--save`可将该次合成样例的脱敏运行轨迹保存到`docs/agent-runs/`。普通玩家请求仅在内存中保留，本服务不会自动将玩家局面或目标写入磁盘。密钥仅保存在本机环境变量或`.env`中。
