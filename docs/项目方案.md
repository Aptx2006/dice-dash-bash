# 《当骰一棒》个人项目方案

## 项目定位

《当骰一棒》是一款可在电脑浏览器运行的类桌游多人回合制竞速游戏。玩家通过房间进入同一棋盘，轮流投掷移动骰和工具骰，选择路线并使用道具，率先到达终点者获胜。房间人数不足时，智能体对手根据当前局面选择合法行动。需求阶段已制作本地可运行原型，用于验证房间、投骰、移动、智能体回合和结算流程；真实联机与云端模型调用仍属于后续实现。

## 目标用户与问题

主要用户是希望与朋友快速开始一局轻量游戏的大学生。他们希望游戏无需安装大型客户端，且人数不足时仍能开局。传统数字派对游戏通常需要购买客户端或特定主机；简单网页棋盘虽然进入方便，但 AI 对手常缺少策略表现和可解释性。

## 核心价值

让玩家通过链接进入房间，并在没有凑齐真人玩家时加入能完成路线和道具决策的智能体，从创建房间到开始可玩对局控制在三分钟以内。

## MVP核心流程

1. 玩家输入昵称并创建房间。
2. 玩家选择地图与角色，加入两名智能体并准备。
3. 系统开始对局，所有参与者按顺序执行投骰、移动、使用道具或结束回合。
4. 服务端校验每次行动并同步房间状态。
5. 某名参与者到达终点后结束对局并展示排名。

## 纳入MVP

- 房间创建、加入、准备与开始
- 一张方格竞速地图
- 2—4名参与者，支持真人和智能体混合
- 回合顺序、移动骰、工具骰和三种道具
- 障碍、奖励和终点地块
- 服务端规则校验与断线重连
- 智能体合法行动选择、超时和规则策略降级
- 对局日志、结果与基础可访问性提示

## 不纳入本学期

- 大规模匹配和赛事系统
- 账号、好友、排行榜和付费功能
- 地图编辑器及玩家内容平台
- 语音、录像、观战和复杂聊天审核
- 多个小游戏和完整角色养成
- 手机原生客户端

## 预期技术栈

TypeScript、Vue 3、Vite、Three.js、Node.js、Colyseus、SQLite。模型只输出结构化行动建议，规则引擎负责合法性和状态变更；模型不可用时使用基于距离、风险和道具收益的确定性策略。

## 成功标准

- 新用户三分钟内创建并开始一局人机对局。
- 一局从开始到结算能够闭环，不出现非法移动或资源负数。
- 智能体在限定时间内给出合法行动；失败时自动降级，不阻塞游戏。
- 断线重连后恢复到服务端确认的最新状态。
