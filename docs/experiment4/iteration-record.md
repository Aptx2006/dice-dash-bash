## 修订版

- createGame 分配状态前验证人数、昵称、地图、角色、颜色和机制字段。
- localStorage 属性访问与读写均在异常保护内；失败返回默认值或警告，不阻断当前操作。
- 暂未实现远端联机，首页加入入口显示明确说明，避免把房间码误当成真实联网会话。
- App 复制普通配置字段，避免重新开局时对 Vue 响应式代理使用 structuredClone 引发异常。
- 增加8项业务边界/闭环测试和4项输入、存储测试，与既有18项规则、相机和动画测试一起运行。

最终自动测试30项全部通过；类型检查和生产构建通过。构建仍有对局分块超过500kB的体积警告，不能据此声称性能已全面达标。
日志见 revised-tests.txt 和 build.txt。

## 人工修正记录

项目作者确认：此前AI生成的动画倍速按钮不够协调，页面缩放适配不好；作者亲自调整为协调的圆角矩形，并修复缩放适配。
此记录来自作者回顾。仓库没有单独保留该次修改前的提交，不能将本次边界修复的差异冒充该次人工样式修改。
当前证据为 GameScreen.vue 的动画速度控件、style.css 中 .speed-control 的圆角和响应式规则，以及1280×800、800×600视口下的浏览器验证。两个视口下控件均完整处于可视区域，速度选项可以选择。
