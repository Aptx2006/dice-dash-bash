# 教学隔离与行动记录

日期：2026-10-28。继续完善游戏，实验6报告仍保留原模板。

## 发现的问题与改进

### 教学会要求覆盖练习

实际点击首页教学入口，原有逻辑因检测到未完成练习而弹出“开始新对局会替换这份存档”。复习教程不应付出丢失正常练习进度的代价。

教学改用`dice-saved-tutorial`独立槽位，练习沿用`dice-saved-match`。两者复用完整快照验证和单次原子写入，但分别读写；地图错误、JSON损坏或存储失败不会改写另一槽位。未完成的教学在首页显示“继续基础教学”，恢复已投出的骰值、手牌与步骤；完成后可以从头练习。旧版本把教学保存在普通槽位的记录仍可打开，后续教学写到新槽位，保留旧原文。

### 引导步骤可以被跳过或取消后不清楚

引导期间按步骤解锁投骰、移动、结束卡，其余手牌保留但不可用。欢迎页和完成页不会提前投骰；选方向时可点击取消或按Esc返回选移动牌，不消耗资源。基础教学期间不展开战术助手，以便玩家亲自练习操作。机器人仍使用正常规则策略和原有动画速度。

`reconcileTutorialStep`根据实际阶段协调进度：投骰后选移动，移动消费后结束行动，第一次结束进入回合结束阶段，第二次结束交出行动权；机器人完成一轮或抵达终点时，出现完成教学按钮。兼容旧教学提前结束阶段的局面。机器人在教程中先赢时，常规结算层不会挡住完成教学入口。教学未改骰子概率、正常地图或胜负规则。

关键文件：[savedMatch.ts](../src/storage/savedMatch.ts)、[App.vue](../src/App.vue)、[tutorial.ts](../src/game/tutorial.ts)、[ToolHand.vue](../src/components/ToolHand.vue)。

## 随时查看最近行动

原桌面日志在960px以下隐藏，玩家错过动画后难以核对刚才的行动。新增记录面板，入口为手牌栏的骰子结果、“规则速查—行动记录”和桌面日志“查看更多”；结算页也可展开。

可搜索玩家、道具或事件，切换最新在前/时间顺序，暂停列表更新阅读。暂停时保存当前可见记录的副本，收到新事件仅提示“有新记录”，点击继续更新再读取最新内容；游戏、AI和时钟始终照常运行。结算后使用已结束说明并去掉无意义的暂停更新按钮。

记录来自规则引擎和服务端已有的公开日志，最多保留40条，随本局存档与联机状态保存；较早记录会移出列表，当前没有完整录像回放。不会借此展示对手未使用的私有手牌。

实际查阅发现普通移动和未命中的方向工具原来没有日志，补充移动牌点数、方向、起点及全部地形结算后的位置，以及拳击/篮球/钩锁/火箭的使用方向；瞬步和瞬移写明选中的落点。非法操作、已消费牌的重复执行和只读推演不写入真实行动记录。历史存档不补造早先缺失的事件。

界面：[MatchHistory.vue](../src/components/MatchHistory.vue)、[MatchRules.vue](../src/components/MatchRules.vue)、[GameScreen.vue](../src/components/GameScreen.vue)。引擎：[engine.ts](../src/game/engine.ts)。
