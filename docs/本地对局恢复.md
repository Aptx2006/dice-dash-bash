# 本地对局恢复迭代

日期：2026-10-15。用户故事：作为本地玩家，我希望刷新或暂时退出后能继续当前对局，不必重新投骰和开局。

## 验收条件

- 每次规则操作完成后自动保存当前配置、棋盘、玩家、手牌、骰值、阶段、奖励、日志及教学进度；计时局保留剩余秒数。
- 首页显示最近对局的地图、人数、回合和存档时间，可继续进行中的对局或查看已结束结果。
- 恢复已经投骰的行动阶段，不再次投骰或发牌；机器人回合、奖励阶段可继续推进。
- 重新载入后分配的牌、实体、日志和特效标识不与存档冲突。
- 新局替换未完成存档前提供取消；退出游戏保留本局进度；教学重开重置引导。
- 缺失、损坏、版本不兼容和存储不可用均给出可理解反馈，失败不能破坏已有存档或阻止本局操作。

范围：单浏览器、单个最近对局的本地存档。不是账号云同步、历史战绩或多人断线重连。离线期间暂停计时；恢复规则已提交的局面，不重播中断的动画或保留尚未提交的目标选择。

## 实现

- `src/storage/savedMatch.ts` 保存格式版本、规则版本、配置和局面；读取前验证地图尺寸、地形、席位、阶段、牌、实体、日志和奖励等嵌套字段。整体JSON通过单次写入替换，写入失败保留原值。
- `restoreGame` 复制已验证状态并预留牌、实体、日志和特效编号，不调用开局和投骰逻辑。
- 页面在同步规则命令完成后保存，计时和教学进度也进入存档；回到首页时立即保存，存储失败则提示是否继续退出。
- 原生确认对话框提供焦点限制与Escape取消。首页未完成对局显示“继续对局”，结束后显示“查看上局结果”。
- 每次重新开局重新挂载对局组件，重置教学、相机、选择和定时器。
- 修复特效列表满30条后不再触发播放的问题，并跳过恢复前的历史特效；回收过期的去重标识。
