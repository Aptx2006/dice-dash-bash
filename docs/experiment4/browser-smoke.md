# 实验4浏览器冒烟记录 B1

日期：2026-10-12。环境：本机开发服务器 http://127.0.0.1:5173/ ，Codex应用内浏览器。通过页面控件的键盘激活完成业务操作，没有注入或改写游戏内部状态。

## 入口与一般对局

1. 首页昵称输入纯空白并创建，页面保留在首页并提示“昵称必须为1至12个字符”。
2. 点击联机说明，提示尚未开放，没有进入伪联机大厅。
3. 输入“小骰”，创建本地房间TV0AXU。大厅只有1名真人时不能开局，添加威猛机器人-333号后可开局。
4. 开局后投骰：移动2、工具钩锁。选择移动并向右，移动牌消耗；结束行动、再次结束，将回合交给机器人。机器人自动完成回合，行动权回到真人。

## 教学关完整结算

1. 从首页进入教学关，玩家“小骰”（村民），默认对手“教学机器人”；计时和空投关闭。
2. 第1回合投骰得到移动3、炸药，选择向右移动，然后两次结束交出回合。
3. 第2回合机器人自动行动：移动1、火箭；第3回合行动权回到小骰，教学面板显示基础教学完成。
4. 第3回合小骰投骰移动5、拳击，继续向右移动，结束并交出回合。
5. 第4回合机器人自动行动：移动6、火箭。
6. 第5回合小骰投骰移动1、钩锁，选择向上移动，结束并交出回合。
7. 第6回合机器人投骰移动6、牵引并抵达终点；界面出现“教学机器人 抵达终点”，小骰显示“未完赛 · 距终点6格”。
8. 结算后手牌操作禁用。点击再来一局，回到第1回合、回合开始，骰值问号且仅有投骰入口，新状态不沿用旧手牌与日志。

投骰结果为本次实际随机结果，复测不要求随机骰值完全相同；确定性终点断言由E4-08补充。
